# CrashTrim

macOS 앱 충돌 리포트에서 식별 정보를 마스킹하고, 분석에 불필요한 부가 정보를 보수적으로 정리하는 네이티브 앱입니다. macOS 14 이상에서 실행하며 Apple Silicon과 Intel을 지원합니다.

## 사용하기

1. 앱의 **붙여넣기** 버튼이나 왼쪽 편집 영역에 문제 리포트를 붙여넣습니다.
2. 필요하면 **추가로 가릴 문자열**에 이름·사내 식별자 등을 줄마다 입력합니다. 대소문자를 구분하며 정규식이 아닌 입력한 문자열 그대로 처리합니다.
3. **마스킹 및 정리**를 누릅니다. 단축키는 `⌘ Return`입니다.
4. 오른쪽 결과를 확인한 뒤 **결과 복사**를 누릅니다. 단축키는 `⇧⌘C`입니다.

원문이나 추가 문자열을 변경하면 이전 결과를 무효화합니다. **모두 지우기**는 앱의 원문·추가 문자열·결과를 지우며, 이미 복사한 클립보드 내용은 유지합니다.

## 처리 정책

- 충돌 리포트 텍스트, 단일 충돌 JSON, 메타데이터와 본문으로 구성된 두 객체 `.ips`를 지원합니다. 문제 리포트 창에서 복사한 번역본과 전체 JSON이 함께 있는 경우 중복 번역본을 제외합니다.
- 계정·이메일·개인 경로·호스트명·네트워크 주소·시리얼·파트 넘버·기기 식별자·절대 시각을 마스킹합니다. 선택한 강한 정책에 따라 Mac 모델·앱 이름과 식별자·바이너리 UUID도 치환합니다.
- 개인 문서 경로는 전체를 가립니다. 앱 실행 경로는 개인 상위 경로와 앱 이름을 치환하고 `.app/Contents/MacOS/…` 구조를 보존합니다. 시스템 라이브러리 경로는 유지합니다.
- 같은 값은 한 번의 처리 안에서 같은 대체 표기를 사용합니다. JSON 숫자형 PID와 사용자 ID는 원래 식별자와 겹치지 않는 대체 숫자로 바꾸며 자료형을 보존합니다.
- 예외·종료 사유, 모든 스레드, 레지스터, 백트레이스, 메모리 주소, 함수명, 버전, 전체 모듈 목록과 모듈 참조 인덱스는 보존합니다. 명확한 리포트 메타데이터와 텍스트의 하드웨어 인벤토리 부록만 제외하고 알 수 없는 섹션은 유지합니다.
- 결과는 텍스트 또는 JSON인 원래 형식을 유지합니다. JSON의 공백·들여쓰기와 객체 키 순서는 정규화됩니다. 추가 문자열을 JSON 키에 직접 지정한 경우 해당 키도 치환되므로 분석 도구의 기대 구조가 달라질 수 있습니다.
- 형식 미인식·파싱 실패 시 원문 구조를 유지하면서 인식 가능한 식별자만 마스킹하고, 정보를 삭제하지 않습니다.

자동 탐지는 알려진 필드와 패턴을 기준으로 합니다. 라벨 없는 시리얼·파트 넘버, 자유로운 진단 메시지 안의 이름과 사내 식별자는 추가 문자열로 지정하세요. 함수명은 진단을 위해 보존하므로 필요하면 추가 문자열로 지정할 수 있습니다. 빌드 UUID 치환으로 원본 dSYM을 사용하는 심볼 복원은 제한됩니다.

로그는 Mac 내부 메모리에서만 처리하며 외부 전송, 자동 저장, 분석 SDK를 사용하지 않습니다. 앱 샌드박스를 사용하고 네트워크 권한을 부여하지 않습니다. 파일 가져오기와 AI 원인 분석은 포함하지 않습니다.

## 빌드와 실행

Xcode 16 이상과 Swift 6을 사용합니다. 외부 패키지 다운로드는 필요하지 않습니다. 터미널에서 아래 명령으로 빌드하고 실행하세요.

```sh
./scripts/build.sh
open build/CrashTrim.app
```

기본은 Release이며 `./scripts/build.sh Debug`로 디버그 빌드도 가능합니다. Apple Silicon과 Intel용으로 빌드한 뒤 서명을 검증하고 `build/CrashTrim.app`을 갱신합니다. 빌드 로그는 `build/build.log`에 남깁니다. 스크립트는 실행한 디렉터리와 관계없이 프로젝트 경로를 사용합니다. `./scripts/build.sh --help`로 사용법을 확인할 수 있습니다.

Xcode에서 실행하려면 `CrashTrim.xcodeproj`를 열고 **CrashTrim** 스킴을 선택하세요.

로컬 실행용 임시 서명을 사용합니다. 배포용 Developer ID 서명과 공증은 별도 작업입니다.

## DMG 생성

```sh
./scripts/create-dmg.sh
```

Release 앱을 빌드한 뒤 `build/CrashTrim.dmg`를 만듭니다. DMG에는 `CrashTrim.app`과 `/Applications` 바로가기가 들어 있으며, 앱을 Applications로 드래그해 설치할 수 있습니다. HFS+ 이미지를 만들고 읽기 전용 압축 형식(UDZO)으로 변환하므로 생성 중 이미지 마운트나 Finder 제어가 필요하지 않습니다. 앱 서명과 압축 디스크 이미지의 체크섬을 검증한 뒤 기존 DMG를 갱신합니다.

이미 빌드한 앱을 패키징하려면 `./scripts/create-dmg.sh --skip-build`를 사용하세요. 실행 디렉터리와 관계없이 프로젝트 경로를 사용하며, `--help`로 사용법을 확인할 수 있습니다. DMG 생성은 배포용 서명이나 공증을 추가하지 않습니다.

## 검증

```sh
xcodebuild -project CrashTrim.xcodeproj -scheme CrashTrim \
  -destination 'platform=macOS' -derivedDataPath build/DerivedData test
```

테스트는 실제 개인정보를 포함하지 않는 합성 리포트를 사용합니다. 식별자 치환, 반복 값의 일관성, 64비트 정수 보존, 모듈 참조, 손상된 형식, 추가 문자열, 긴 로그, 입력 변경·처리 취소, 복사·초기화를 검증합니다. 시스템 클립보드 검증은 사용자 클립보드 대신 별도 테스트 클립보드를 사용합니다.

핵심 엔진은 `Core`의 독립 Swift 패키지로도 테스트할 수 있습니다.

```sh
swift test --package-path Core
```

제한된 실행 환경에서 Xcode의 테스트 관리 서비스에 접근할 수 없다면 번들을 빌드하고 XCTest를 직접 실행할 수 있습니다.

```sh
xcodebuild -project CrashTrim.xcodeproj -scheme CrashTrim \
  -destination 'platform=macOS' -derivedDataPath build/DerivedData build-for-testing
xcrun xctest build/DerivedData/Build/Products/Debug/CrashTrimTests.xctest
```

이 환경에서도 시스템 클립보드 서비스가 차단되면 해당 통합 테스트만 건너뛰며, 메모리 클립보드를 이용한 앱의 붙여넣기·복사 흐름 테스트는 실행합니다.
